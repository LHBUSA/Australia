PROPDATA · AU

Build on Australian property identity.

PropData Australia exposes an expanding, source-native Australian property graph through the same country-aware contract used across the global PropData network. Coverage is explicit: live source facts are returned as facts; expanding layers are never silently fabricated.

Quick start

Send country=AU with the strongest identity you have. In production, authenticate with your PropData API key.

curlAU property lookup
curl "https://api.proptechusa.ai/v1/property?country=AU&address=YOUR_ADDRESS" \ -H "X-API-Key: $PROPDATA_API_KEY"
Important: Australian coverage is expanding. Treat coverage_status, match_level and provenance as first-class response fields rather than assuming every state currently exposes the same source depth.

Country-aware contract

Australia is not normalized by deleting jurisdiction semantics. The stable API contract wraps native source identifiers and relationships.

countryISO country code, always AU for this product.

Coverage semantics

The Australia product intentionally distinguishes product availability from dataset completeness. Queensland's parcel/address baseline is live. National G-NAF and additional states are rolling into the contract.

  • live — the source layer is available for production lookup.
  • expanding — the layer is actively being loaded or broadened.
  • partial — a valid property can be resolved but not every enrichment is present.
  • unavailable — PropData does not have a verified source fact for that layer.

Identity before enrichment

Australian source identifiers can differ by jurisdiction. PropData keeps them visible rather than replacing them with an invented universal parcel number.

Queensland

QSCF parcel identity and QAMF address identity are live. Native source record IDs remain linked to PropData global IDs.

National G-NAF

G-NAF address detail PIDs become the national address spine as the state-partitioned baseline advances.

NSW and Victoria

NSW prop_id and Victoria SPI/property identifiers are designed to remain first-class native identifiers in the source-aware graph.

Provenance

Every Australian source layer is expected to remain traceable to the authority that published it. Source name, dataset ID, source record ID, revision and fetched timestamp are preserved where available.

responseprovenance shape
"provenance": { "source_name": "Queensland Spatial Cadastral Fabric", "source_dataset_id": "QSCF Lot parcels", "source_revision": "2026-08", "jurisdiction": "QLD" }
